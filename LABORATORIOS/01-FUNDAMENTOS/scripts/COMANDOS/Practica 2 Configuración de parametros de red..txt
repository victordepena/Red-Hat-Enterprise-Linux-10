1. Configurar la IP estática
sudo nmcli con mod "ens160" ipv4.addresses 192.168.1.50/24

2. Configurar la puerta de enlace (Gateway)
sudo nmcli con mod "ens160" ipv4.gateway 192.168.1.1

3. Cambiar el método de automático (dhcp) a manual
sudo nmcli con mod "ens160" ipv4.method manual

4. Configurar los DNS de Google
sudo nmcli con mod "ens160" ipv4.dns "8.8.8.8,8.8.4.4"

5. Reiniciar la conexión para aplicar los cambios
sudo nmcli con up "ens160"

----------------------------------------

1. Cambiar el método a automático (DHCP)
sudo nmcli con mod "ens160" ipv4.method auto

2. Asignar los DNS de Google
sudo nmcli con mod "ens160" ipv4.dns "8.8.8.8,8.8.4.4"

3. (Opcional) Ignorar los DNS que envíe el servidor DHCP
sudo nmcli con mod "ens160" ipv4.ignore-auto-dns yes

4. Reiniciar la conexión
sudo nmcli con up "ens160"
